# create-agentsmd

## 适用Agent
Custom Agent Foundry Agent、Skill Creator Agent

## 触发条件
当用户需要为项目生成AGENTS.md文件时触发。AGENTS.md是为AI编码Agent提供项目上下文和指令的开放格式文件。

## 概述
创建高质量的AGENTS.md文件，遵循https://agents.md/的公开指南。AGENTS.md是"Agent的README"——为AI编码Agent提供工作所需的上下文和指令。

## 什么是AGENTS.md？
AGENTS.md是一个Markdown文件，作为"Agent的README"——一个专门的、可预测的位置，提供上下文和指令帮助AI编码Agent在项目上工作。它补充README.md，包含编码Agent需要的详细技术上下文，避免人-focused的README过于臃肿。

## 关键原则
- **面向Agent**：包含自动化工具的详细技术指令
- **补充README.md**：不替代人类文档，而是添加Agent特定的上下文
- **标准化位置**：放在仓库根目录（或monorepo的子项目根目录）
- **开放格式**：使用标准Markdown，结构灵活
- **生态兼容**：适用于20+不同的AI编码工具和Agent

## 执行步骤

| 序号 | 步骤 | 详细执行方式 |
|------|------|-------------|
| 1 | 分析项目结构 | 识别使用的编程语言和框架、包管理器和构建工具、测试框架、项目架构（monorepo、单包等） |
| 2 | 识别关键工作流 | 检查package.json脚本、Makefile或其他构建文件、CI/CD配置文件、文档文件 |
| 3 | 创建综合章节 | 覆盖所有必要的设置和开发命令、测试策略和命令、代码风格和约定、构建和部署过程 |
| 4 | 包含具体命令 | 包含Agent可以直接执行的具体可操作命令 |
| 5 | 测试指令 | 确保所有列出的命令按文档所述工作 |
| 6 | 保持聚焦 | 专注于Agent需要知道的，而非一般项目信息 |

## Monorepo考虑
对于大型monorepo：
- 在仓库根目录放置主AGENTS.md
- 在子项目目录创建额外的AGENTS.md文件
- 最近的AGENTS.md文件对任何给定位置优先
- 包含包/项目之间的导航提示

## 最佳实践

| 实践 | 说明 |
|------|------|
| 要具体 | 包含确切命令，而非模糊描述 |
| 使用代码块 | 用反引号包裹命令以增强清晰度 |
| 包含上下文 | 解释为什么需要某些步骤 |
| 保持更新 | 随项目演进更新 |
| 测试命令 | 确保所有列出的命令实际可工作 |
| 考虑嵌套文件 | Monorepo在子项目创建AGENTS.md |

## 输出规范

| 序号 | 规范项 | 要求 |
|------|--------|------|
| 1 | 文件位置 | 项目根目录的`AGENTS.md` |
| 2 | 格式 | 标准Markdown |
| 3 | 优先级 | 清晰性、完整性、可操作性 |
| 4 | 目标 | 给任何编码Agent足够的上下文来有效贡献项目，无需额外人工指导 |
| 5 | 生态兼容 | 适用于20+ AI编码工具（Cursor、Aider、Gemini CLI等） |
