# testing

## 适用Agent
测试Agent

## 触发条件
代码开发Agent产出代码后触发。

## 执行步骤

| 序号 | 步骤 | 详细执行方式 |
|------|------|-------------|
| 1 | 读取上游文档 | 读取`output/requirements/`下需求规格文档、`output/technical-design/`下技术设计文档、`output/code/`下最新代码文件列表 |
| 2 | 制定测试方案 | 根据需求规格和技术设计，确定测试范围和策略，以表格列出：测试类型（单元测试/集成测试/E2E测试）、覆盖模块、测试环境要求、工具选型 |
| 3 | 编写单元测试用例 | 为每个Service方法编写单元测试，测试用例以表格列出：用例编号（UT-{类名}-{序号}）、测试方法、输入数据、预期输出、边界条件，测试代码写入`output/code/`下`src/test/`对应目录 |
| 4 | 编写集成测试用例 | 为每个API接口编写集成测试，使用Testcontainers管理测试数据库容器，测试用例以表格列出：用例编号（IT-{接口编号}-{序号}）、测试场景、请求参数、预期响应状态码、预期响应体、异常场景，测试代码写入`output/code/`下`src/test/`对应目录 |
| 5 | 安全测试 | 对代码进行安全检查：(1) 按OWASP Top 10逐项检查常见漏洞（注入/XSS/CSRF/不安全反序列化等），以表格列出：风险编号（SEC-NNN）、风险类别、是否存在、检查结果、修复建议；(2) 建议集成CodeQL代码扫描（在CI/CD中配置codeql.yml），支持Java/Kotlin/JavaScript/TypeScript/Python |
| 6 | 验证验收标准 | 逐一核对需求规格文档中的P0/P1验收标准，将每条验收标准映射到对应的测试用例，以表格列出：验收标准编号、对应测试用例编号、验证结果 |
| 7 | 记录缺陷 | 测试不通过的用例，记录缺陷信息：缺陷编号（BUG-{序号}）、严重程度（致命/严重/一般/提示）、缺陷类型（功能/安全/性能）、复现步骤、预期结果、实际结果、分配给（对应代码开发Agent） |
| 8 | 生成测试文档 | 整合测试方案、测试用例表、安全检查表、验收标准映射表、缺陷清单为测试报告文档，以Markdown格式写入`output/test/`目录，文件命名为`test-report-{yyyy-MM-dd}.md` |

## 安全检查清单（OWASP Top 10）

| 序号 | 风险类别 | 检查要点 |
|------|----------|----------|
| 1 | 注入攻击 | SQL参数化查询、输入校验、ORM使用 |
| 2 | 失效的身份认证 | 密码策略、Session管理、多因素认证 |
| 3 | 敏感数据泄露 | 数据加密（传输/存储）、敏感字段脱敏 |
| 4 | XML外部实体(XXE) | XML解析器配置、禁用外部实体 |
| 5 | 失效的访问控制 | 权限校验、越权防护、CORS配置 |
| 6 | 安全配置错误 | 默认账号/密码、不必要的服务、错误信息泄露 |
| 7 | 跨站脚本(XSS) | 输出编码、CSP策略、输入过滤 |
| 8 | 不安全的反序列化 | 白名单校验、签名验证 |
| 9 | 使用含有已知漏洞的组件 | 依赖版本检查、SCA扫描 |
| 10 | 日志与监控不足 | 安全事件日志、异常监控、告警机制 |

## CodeQL集成建议

在CI/CD工作流中配置CodeQL代码扫描：

| 配置项 | 建议值 |
|--------|--------|
| 触发条件 | push到main分支、Pull Request、每周定时扫描 |
| 语言矩阵 | java-kotlin, javascript-typescript |
| 查询套件 | security-extended |
| 构建模式 | autobuild（Java）、none（JS/TS） |
| 输出格式 | SARIF（上传到GitHub Security tab） |

## 输出规范

| 序号 | 规范项 | 要求 |
|------|--------|------|
| 1 | 格式 | Markdown + 测试代码 |
| 2 | 覆盖率 | P0需求100%覆盖，P1需求80%以上覆盖 |
| 3 | 代码规范 | 测试代码同样遵循生产代码规范 |
| 4 | 缺陷跟踪 | 每个缺陷必须关联到具体代码开发Agent |
| 5 | 安全检查 | 必须包含OWASP Top 10逐项检查结果 |
| 6 | 集成测试 | 必须使用Testcontainers管理测试环境 |
