## 10. 使用说明

### 10.1 模板使用规则

1. **必填字段**：所有带`[ ]`的字段必须填写，不得留空
2. **可选字段**：如某些字段不适用，填写"N/A"并说明原因
3. **完整性要求**：所有功能必须完整描述，步骤必须清晰
4. **一致性要求**：用户文档与需求文档、设计文档保持一致
5. **可读性要求**：语言必须通俗易懂，避免专业术语

### 10.2 AI自动化开发适配

1. **结构化格式**：所有内容使用表格或结构化格式，便于AI解析
2. **步骤化描述**：所有操作必须提供明确步骤，便于AI理解
3. **明确关系**：元素之间的关联关系必须明确标注
4. **完整覆盖**：用户文档必须覆盖所有功能和场景
5. **可验证性**：每个操作步骤必须有可验证的预期结果

### 10.3 与其他文档的关系

| 文档 | 关系 | 说明 |
|------|------|------|
| 需求文档 | 输入 | 需求文档是用户文档的依据 |
| 设计文档 | 输入 | 设计文档是用户文档的依据 |
| 测试文档 | 输入 | 测试文档是用户文档的验证依据 |
| 部署文档 | 输入 | 部署文档是安装部署章节的依据 |
