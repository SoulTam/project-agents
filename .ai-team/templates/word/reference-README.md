# Word参考模板说明

> 本目录存放Word文档输出的参考模板。

## 使用方式

将企业Word模板文件命名为`reference.docx`放置于此目录。Pandoc将基于此模板的样式生成Word文档。

## 模板要求

| 样式项 | 要求 |
|--------|------|
| 封面页 | 包含文档标题、副标题、日期、作者占位符 |
| 标题1 | 黑体，三号，加粗，段前段后12pt |
| 标题2 | 黑体，四号，加粗，段前段后6pt |
| 标题3 | 黑体，小四号，加粗，段前段后3pt |
| 正文 | 宋体，小四号，行距1.5倍 |
| 表格 | 表头加粗居中浅蓝底色，正文左对齐，边框单线 |
| 代码块 | Consolas字体，五号，浅灰底色 |
| 页眉 | 左侧文档标题，右侧公司名称 |
| 页脚 | 居中页码 |
| 目录 | 自动生成，链接到标题 |

## 默认行为

若此目录无`reference.docx`文件，Pandoc将使用默认模板，输出样式为Pandoc默认格式。
