# PPT模板说明

> 本目录存放PPT文档输出的演示模板。

## 使用方式

将PowerPoint模板文件命名为`template.pptx`放置于此目录。python-pptx将基于此模板的布局和样式生成幻灯片。

## 模板要求

| 布局项 | 要求 |
|--------|------|
| 封面布局 | 包含标题占位符、副标题占位符、日期占位符 |
| 目录布局 | 标题+要点列表 |
| 内容布局 | 标题+要点列表 或 标题+表格 |
| 总结布局 | 标题+要点列表 |
| 字体 | 中文微软雅黑，英文Calibri |
| 标题字号 | 28pt |
| 正文字号 | 18pt |
| 配色 | 统一企业配色方案（主色、辅色、强调色） |
| 页脚 | 右下角页码 |

## 模板中需定义的Slide Layout

| 布局名称 | 用途 |
|----------|------|
| Title Slide | 封面 |
| Section Header | 章节分隔 |
| Title and Content | 正文内容 |
| Two Content | 双栏内容 |
| Comparison | 对比 |
| Blank | 空白（备用） |

## 默认行为

若此目录无`template.pptx`文件，python-pptx将使用默认布局。
