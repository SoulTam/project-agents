# 模板：请求分类（G1 前置）

> 加载条件：每个新请求。单次只加载本模板。

## 请求分类

| 字段 | 值 |
|------|-----|
| 请求类型 | 需求 / 修改 / 咨询 / 调试 / 优化 / 能力变更 |
| 核心意图 | 一句话，≤40 字 |
| 目标 | 完成后世界是什么样，一句话 |
| 级别 | L0 / L1 / L2 / L3 |
| 判定理由 | 引用 R-LV 的判定条件原文 |
| 涉及 Skill | 命中的 `SKILL: name@ver`，未命中写"无" |

## 级别判定口径（R-LV）

| 级别 | 判定条件 | 确认次数 | 关卡 | 产出物 |
|------|---------|---------|------|--------|
| L0 | 纯问答、无文件变更 | 0 | 无 | 无 |
| L1 | 单文件或 ≤50 行改动、无接口/数据变更 | 1（S2） | G4 轻量（自查+证据） | 变更摘要 |
| L2 | 跨文件/跨模块、含接口或数据变更 | 2（S3+S4） | G1–G5 | D3/D4/D5 |
| L3 | 改 agent/skill/规则本身、或吸收外部能力 | 3（S3+S4+S8） | G1–G5 + 元审计 | D3/D4/D5/D7/D8 |
