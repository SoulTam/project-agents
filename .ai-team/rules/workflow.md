# 工作流程规则

> 硬规则正文见 `AGENTS.md`（R-HR-01..10）。本文件只写操作规程，不复制硬规则原文。
> 状态与日志见 `gate-rules.md`；角色契约见 `.ai-team/agents/`。

---

## 1. 角色识别

| 情况 | 处理 |
|------|------|
| 用户指定"作为 XX Agent" | 以指定角色执行，仍受 R-HR 约束 |
| 用户未指定 | 默认 PM Agent |
| 收到非 PM 角色任务 | 仅在被 PM 调用时激活，产出回 PM |

## 2. 请求进入序列

```
[1] 读 agent-doc/tasks/{task_id}/status.md（无则新建）
[2] 判定级别（R-LV），写入 D1
[3] 按级别分流
    L0 → 直接应答（不产物）
    L1 → brief.md → 1 次确认 → 执行 → 证据回填
    L2 → blueprint.md → G2 → 用户确认 → plan-breakdown.md → G3 → 用户确认 → 执行
    L3 → 同 L2，追加 intake/元审计（G5）
[4] 每步更新 D1 + 追加 D2
```

## 3. 规程要点

| 规程 | 要求 |
|------|------|
| 分级 | 采用 R-LV 判定表；判不清先追问 1 次，仍不清按 L2 |
| 蓝图 | 四维度必须全填；不适配项目按模板"维度映射"表换算，不得留空维度 |
| 子计划 | 每 SP 独立文件；`final_result` 由 `blueprint_split.py` 生成 |
| 执行 | 逐行按子计划"怎么做/正反约束"执行，禁止自行发挥 |
| 证据 | 每个断言记录实际输出与退出码；无证据即 fail（R-HR-03） |
| 驳回 | 同关同任务最多 2 轮；第 3 轮升级用户（R-HR-05） |
| 状态 | 只认 D1；对话历史不作为状态依据（R-HR-06） |
| 提交 | 每 SP 一次；每 3 个 SP 强制提交 |

## 3.1 五关卡（G1–G5）

| 关卡 | 时机 | 判定者 | 通过条件 | 证据要求 |
|------|------|--------|---------|---------|
| G1 输入门禁 | 分级后（L2/L3） | PM | 目标一句话 + ≥1 可机读验收 + ≥1 verify_cmd | 三项各 1 条 |
| G2 蓝图审计 | 蓝图产出后 | 核查 subagent | 15/15 自检 + 交叉校验 4/4 + 无"提及未设计" | 逐项 file:line |
| G3 覆盖核查 | 子计划产出后 | 核查 + `gate_check.py` | BLK 覆盖 100%、跳转词 0、省略词 0 | 脚本退出码 0 |
| G4 执行双卡 | 每个 SP 后 | 核查 + 稽查 + 测试 | 步骤全实现 + 无违规 R-ID + 断言全过 | 2 份报告 + verify_cmd 退出码 |
| G5 终态校验 | 全部 SP 后 | 核查 + `gate_check.py` | BLK 全实现 + 元审计 10/10 | BLK 定位表 + 退出码 0 |

| 项 | 约束 |
|----|------|
| 驳回 | 同关同任务最多 2 轮，第 3 轮升级用户（R-HR-05） |
| 报告 | `reports/{gate}-{kind}-report.json`，字段见 `gate-rules.md` 第 7 节 |
| 判定 | 只用 pass/fail/escalated；无证据按 fail（R-HR-03） |

## 4. 阶段与模板

| 阶段 | 模板 | 加载条件 |
|------|------|---------|
| 分级 | `.ai-team/templates/stages/classify.md` | 每个新请求 |
| 轻量变更 | `.ai-team/templates/stages/brief.md` | L1 |
| 蓝图 | `.ai-team/templates/stages/blueprint.md` | L2/L3 |
| 计划拆分 | `.ai-team/templates/stages/plan-breakdown.md` | 蓝图确认后 |
| 子计划执行 | `.ai-team/templates/stages/execute.md` | 进入执行 |
| 终态校验 | `.ai-team/templates/stages/final-check.md` | 全部 SP 完成 |

单次只加载 1 个模板；跨阶段复用需重新声明。

## 5. 强制暂停点

| 序号 | 暂停点 | 适用级别 | 用户动作 |
|------|--------|---------|---------|
| 1 | 轻量变更卡 | L1 | 确认 |
| 2 | 结果蓝图 | L2/L3 | 确认 |
| 3 | 子计划清单 | L2/L3 | 确认 |
| 4 | 能力吸收报告 | L3 | 确认 |
| 5 | 升级裁决 | 任意（驳回超限） | 裁决 |

## 6. 禁止行为

| # | 禁止 |
|---|------|
| 1 | 未定级即开始执行 |
| 2 | L0/L1 产出蓝图或子计划 |
| 3 | 一次输出多个阶段模板 |
| 4 | 无证据声明"通过/完成" |
| 5 | 自行修改子计划验收标准以通过关卡 |
| 6 | 修改 `gate-log.jsonl` 历史行 |
| 7 | 引用 `agent-doc/` 之外的临时路径作为证据 |
