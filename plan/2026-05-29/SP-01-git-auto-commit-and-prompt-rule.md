# SP-01: Git自动提交 + 提示词工程师使用规则

## 类型
A（规则修改）

## 技术栈
文档/规则

## 对应蓝图章节
全部（工作流规则修改）

## 前置依赖
无

## 负责子Agent
code-dev/doc

## 执行步骤

### Step 1: 在 instructions.md 头部添加提示词工程师使用规则
- 在 "每次收到消息，按以下步骤执行：" 列表后，添加一条备注
- 内容：明确哪些指令可跳过提示词增强（确认/可以/确认执行/停止执行等简短指令），其余一律先走提示词工程师模板

### Step 2: 在 "阶段：子计划执行" 模板中嵌入Git自动提交规则
- 在 "### 执行步骤" 段落下方插入 "### Git自动提交规则" 段落
- 内容：每完成3个子计划自动执行 git add . + git commit
- 提交信息格式：`auto: SP-[起始编号] to SP-[结束编号] 子计划完成`

### Step 3: 更新 workflow-status.md（如适用）

## 验收标准
1. instructions.md 头部明确可见提示词工程师使用规则
2. 子计划执行模板中包含完整的Git自动提交规则描述
3. 计数器逻辑清晰：每3个子计划触发一次提交

## 测试验证
1. 检查规则文本是否完整无歧义
2. 确认无语法或格式错误
