# 功能设计文档：文档元数据时间戳规则

## 行为规则
| 场景 | 行为 |
|------|------|
| 创建新文档 | 写入 `创建时间` 和 `最后修改`（相同值） |
| 更新已有文档 | 更新 `最后修改` 时间，`创建时间` 保持不动 |
| 无文件变更 | 不操作 |
| 处理源代码文件 | 跳过，不添加 |

## 验收标准
- 所有非代码文档头部格式统一
- 创建时间在文件创建时固定，后续不再变化
- 最后修改时间随每次文件更新而刷新
- 源代码文件不受影响
