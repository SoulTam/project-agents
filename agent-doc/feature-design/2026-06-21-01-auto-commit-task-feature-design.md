# 功能设计文档：修改任务完成后自动提交规则

## 功能描述
在 AGENTS.md 中新增一条 Git 自动提交规则：任何修改任务完成后自动执行 `git add . && git commit`。

## 行为规则
| 场景 | 行为 |
|------|------|
| 修改1个文件后（如更新文档） | 立即提交 |
| 修改多个文件（同一任务） | 合并为1次提交 |
| 纯对话交互（无文件变更） | 不触发 |
| 与"回复结束后"规则同时触发 | 执行1次提交（去重） |
| git status 无变更 | 跳过 |

## 验收标准
- 规则C的描述清晰无歧义地写入 AGENTS.md
- 规则C与规则A/规则B的关系明确（不冲突、有去重策略）
- 15项自检全部通过
