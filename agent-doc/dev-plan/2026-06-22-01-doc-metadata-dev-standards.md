# 开发规范文档：文档元数据时间戳规则

## 规范要求
所有非代码文档（.md 为主）必须在文件最开头包含：
```
<!-- 创建时间: yyyy-MM-dd HH:mm -->
<!-- 最后修改: yyyy-MM-dd HH:mm -->
```

## 维护规则
- 新建文档 → 必须写入时间戳头部
- 修改文档 → 必须更新"最后修改"时间
- 时间格式 → `yyyy-MM-dd HH:mm`（24小时制）
- 排除 → 源代码文件不添加

## 审计要求
- 核查Agent检查文档头部是否包含时间戳
- 稽查Agent验证时间格式是否正确
