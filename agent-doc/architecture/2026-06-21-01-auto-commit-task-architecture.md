# 架构设计文档：修改任务完成后自动提交规则

## 概述
在 AGENTS.md 的"Git 自动提交规则（所有阶段适用）"章节中，新增一条规则：任何修改任务（文件/代码/文档变更）完成后自动执行 Git 提交。

## 架构决策
| 决策 | 选择 | 理由 |
|------|------|------|
| 触发时机 | 每次修改任务完成后 | 与现有"每次回复结束后"互补，提供更细粒度的保护 |
| 规则位置 | AGENTS.md "Git 自动提交规则"章节 | 与现有两条规则（回复结束/3个子计划）集中管理 |
| 适用范围 | 所有阶段 | 统一规则，无需分阶段定义 |
| 冲突策略 | 取最具体的规则执行 | 避免重复提交同一变更 |

## 规则层次关系
```
AGENTS.md
  └── Git 自动提交规则（所有阶段适用）
       ├── 已有规则A：每次回复结束后自动提交
       ├── 已有规则B：每完成3个子计划自动提交
       └── 新增规则C：每次修改任务完成后自动提交
```

规则C是规则A的补充：规则A关注"输出时机"，规则C关注"任务完成时机"。两者可能同时触发，采用"一次提交"去重策略（通过 git status --porcelain 检查是否有变更）。
