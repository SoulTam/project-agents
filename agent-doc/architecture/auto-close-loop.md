# 工作流自动化闭环 — 架构设计

## 概述
重构工作流自动化边界：仅3处需用户确认，子计划执行阶段全自动闭环，全部完成后通知用户检查。

## 架构决策
| 决策 | 选择 | 理由 |
|------|------|------|
| 用户确认节点 | 提示词增强 / 结果蓝图 / 子计划清单 | 仅这3处需要用户输入确认 |
| 执行期推进 | 核查+稽查自动判断 | 通过→继续，不通过→PM修正，无需用户介入 |
| PM修正 | 自动分配修正后重新走完整核查稽查 | 确保修正质量 |
| 完成通知 | 全部执行完后等待用户聊天反馈 | 零额外通知机制 |
