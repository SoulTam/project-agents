# 用户请求记录

所有文档必须在文件最开始记录生成时间和最后修改时间。每次更新需要更新最后修改时间。

**约束条件**：
- 技术：Markdown 文件，使用统一格式
- 质量：保持格式统一，所有文档头部格式一致
- 维护：每次文件修改后自动更新最后修改时间

**期望输出**：规则定义 + 已有文档批量更新
