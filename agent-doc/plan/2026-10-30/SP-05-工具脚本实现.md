## 完整设计内容（逐字拷贝自蓝图）

### 脚本入参/出参/退出码

| 脚本 | 入参 | 出参 | 退出码 | 关键逻辑 |
|------|------|------|--------|---------|
| `gate_check.py` | `--task`, `--gate`, 可选 `--report` | JSON stdout | 0/1/2 | 校验 D5 schema；`failed>0` → 1；证据缺失 → 2 |
| `blueprint_split.py` | `--blueprint`, `--map`, `--out` | 生成的 SP 文件 | 0/1 | 按 BLK 抽取；缺失 BLK → 1 |
| `metadata_check.py` | 路径列表 | 违规清单 | 0/1 | 首两行正则 `<!-- (创建时间\|最后修改): yyyy-MM-dd HH:mm -->` |
| `registry_lint.py` | 无 | 违规清单 | 0/1 | name 唯一、path 存在、keyword 不交叉、agents 合法 |
| `link_check.py` | 无 | 死链清单 | 0/1 | 扫描 `.md` 中反引号路径与 `](./...)` 链接 |

### 脚本禁止项（源自蓝图）

| 项 | 约束 |
|----|------|
| 副作用 | 只允许写 `--out` 指定路径；禁止改动业务文件 |
| 联网 | 禁止 |
| 幂等 | 同输入同输出，重复执行无差异 |
| 输出 | stdout 只输出 JSON；诊断信息走 stderr |
| 依赖 | 仅 Python 3.11+ 标准库 |

### gate_check.py JSON 输出契约（实施规格）

```json
{
  "ok": false,
  "exit": 2,
  "gate": "G3",
  "task_id": "T2026-1030-01",
  "checked": 42,
  "failed": 0,
  "reasons": ["evidence empty"],
  "blocking": ["BLK:API-007"]
}
```

### BLK 解析规则（实施规格）

| 规则 | 说明 |
|------|------|
| 起始标记 | `<!-- BLK:<NS>-<NNN> -->` |
| 结束边界 | 下一个 BLK 标记或同级 `##`/`###` 标题 |
| 内容保留 | 原样保留，包括缩进、表格分隔线、代码块围栏 |
| 缺失处理 | `--map` 中声明但蓝图中不存在 → 退出码 1 |
| 重复处理 | 同 BLK 出现两次 → 退出码 1 |
