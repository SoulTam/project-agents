| ID | 规则 | 约束 |
|----|------|------|
| R-HR-01 | 单一真相源 | `AGENTS.md` ≤120 行，只含门禁+分级+路由；规则本体在 `rules/`，方法在 `skills/`；跨层只允许引用 ID，禁止复制原文 |

| R-HR-04 | 自检独立 | 核查/稽查/测试以 subagent 运行，输入只含"产物路径+判定标准+输出 schema"，不得携带 PM 结论 |

| R-HR-10 | 能力变更准入 | 新增/修改 agent/skill/规则必须走 intake 或元审计，附回归用例结果；许可未知一律拒绝 |

### 分级判定表（`R-LV`）

| 级别 | 判定条件 | 确认次数 | 关卡 | 产出物 |
|------|---------|---------|------|--------|
| L0 | 纯问答、无文件变更 | 0 | 无 | 无 |
| L1 | 单文件或 ≤50 行改动、无接口/数据变更 | 1（S2） | G4 轻量（自查+证据） | 变更摘要 |
| L2 | 跨文件/跨模块、含接口或数据变更 | 2（S3+S4） | G1–G5 | D3/D4/D5 |
| L3 | 改 agent/skill/规则本身、或吸收外部能力 | 3（S3+S4+S8） | G1–G5 + 元审计 | 追加 D7/D8 |

### 状态流转（`R-ST`）

| 当前 | 允许迁移 | 禁止 |

| 蓝图 | 子计划（G2 pass）/ 蓝图（G2 fail，round<2）/ 已升级（round=2） | 跳过 G2 |

## 完整设计内容（逐字拷贝自蓝图）

### 关卡定义（G1–G5 骨架规格）

| 关卡 | 触发时机 | 判定者 | 通过条件 | 证据要求 | 驳回条件 |
|------|---------|--------|---------|---------|---------|
| G1 输入门禁 | 分级完成、进入 L2/L3 | PM 自检 | 目标一句话 + 验收 ≥1 条可机读 + `verify_cmds` ≥1 | 验收项含 cmd 或 file:line | 验收不可机读 |
| G2 蓝图审计 | 蓝图产出后 | 核查 subagent | 15/15 自检通过 + 交叉校验 4/4 + 无"提及未设计" | 报告 JSON + 检查项计数 | 任一维度缺字段 |
| G3 覆盖核查 | 子计划产出后 | 核查 subagent + `gate_check.py` | BLK 覆盖率 100%、跳转词 0、省略词 0 | `gate_check.py` 退出码 + 报告 | 任一 BLK 未引用 |
| G4 执行双卡 | 每个 SP 执行后 | 核查 + 稽查 subagent + `verify_cmd` | 内容：步骤/验收全达成；合规：无违规 R-ID | 测试退出码 + 两份报告 | 任一验收断言失败 |
| G5 终态校验 | 全部 SP 完成 | 核查 subagent + `gate_check.py` | 蓝图 BLK 全被实现 + 无引擎证据缺失 | 报告 + BLK 清单 | BLK 未覆盖 |

### D5 gate-report.json 完整字段

| 字段 | 类型 | 必填 | 约束 |
|------|------|------|------|
| gate | string | 是 | G1–G5 |
| kind | enum | 是 | blueprint/coverage/content/compliance/test/final |
| task_id | string | 是 | 与目录一致 |
| round | int | 是 | ≥1 |
| verdict | enum | 是 | pass/fail/escalated |
| checked | int | 是 | ≥0 |

| evidence | list | 是 | `{type(file/cmd), ref, result}` |
| blocking | list | fail 必填 | R-ID 或 BLK-ID |
| ts | datetime | 是 | ISO 8601 |
