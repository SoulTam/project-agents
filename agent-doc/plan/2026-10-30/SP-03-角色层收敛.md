## 完整设计内容（逐字拷贝自蓝图）

### 各角色可写域（实施规格，源自 R-PM）

| 角色 | 可写路径 | 禁写路径 |
|------|---------|---------|
| PM | `agent-doc/tasks/{id}/status.md`、`gate-log.jsonl`、`agent-doc/plan/**`、`agent-doc/result-first/**` | `agent-doc/code/**`、`agent-doc/tasks/{id}/reports/**`、`.ai-team/skills/**` |
| 核查 | `agent-doc/tasks/{id}/reports/*verification*.json` | 其余全部 |
| 稽查 | `agent-doc/tasks/{id}/reports/*audit*.json`、`agent-doc/audit/**` | 其余全部 |
| 测试 | `agent-doc/tasks/{id}/reports/*test*.json`、`agent-doc/code/**/test/**` | `.ai-team/**` |
| 代码开发 | `agent-doc/code/**` | `.ai-team/**`、`agent-doc/tasks/{id}/*.md` |
| Creator | `.ai-team/skills/**`、`.ai-team/agents/**`、`agent-doc/tasks/{id}/intake/**` | `agent-doc/code/**` |

### 判定角色 subagent 输入输出契约（实施规格）

| 角色 | 输入（仅此三项） | 禁止输入 | 输出 |
|------|----------------|---------|------|
| 核查 | `artifacts[]`（文件路径）、`criteria`（判定标准文件路径）、`schema`（D5 字段定义） | 对话历史、PM 结论、上一次报告结论 | D5(kind=blueprint/coverage/content/final) |
| 稽查 | `task_dir`、`rule_ids[]`、`schema` | 同上 | D5(kind=compliance) |
| 测试 | `sp`、`verify_cmds[]` | 同上 | D5(kind=test) + 命令原始输出 |

### 稽查检查项（R-AU 规格）

| ID | 检查项 | 依据 | 判定方式 |
|----|--------|------|---------|
| R-AU-01 | 是否产出 level 并写入 D1 | R-HR-02 | 读 D1，缺失即 fail |
| R-AU-02 | 模板是否按需加载（单次 ≤1） | R-HR-09 | 查回复中模板标题出现次数 |
| R-AU-03 | 是否引用不存在的路径 | 通用 | `link_check.py` |
| R-AU-04 | 是否越域写入 | R-PM | 对比可写域表与 git diff 路径 |
| R-AU-05 | 是否使用未注册 Skill | R-HR-07 | 对比 registry.json |
| R-AU-06 | 子计划是否含 verify_cmd 与 acceptance | R-HR-08 | 读 D4 |
| R-AU-07 | gate-log 是否被改写 | R-HR-06 | `git diff` 历史行 |
| R-AU-08 | 是否无证据声明通过 | R-HR-03 | 检查 D5.evidence 是否为空 |
