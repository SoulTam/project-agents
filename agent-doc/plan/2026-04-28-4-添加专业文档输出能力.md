# 执行计划：添加专业文档输出能力

## 目标

为AI团队添加专业文档输出能力，将Markdown产出物转换为Word、PDF、Excel、PPT格式，达到企业级专业水准。

## 分析

### 当前状态

各Agent产出Markdown格式文档存放于`output/`目录，无法直接用于项目汇报、客户交付、演示等场景。

### 需要解决的核心问题

| 问题 | 说明 |
|------|------|
| 格式转换 | Markdown → Word/PDF/Excel/PPT |
| 专业排版 | 非简单转换，需要企业级模板、样式、排版规范 |
| 内容适配 | 不同文档类型需要不同的内容组织方式（如PPT需要精简要点，Excel需要数据表格化） |
| 模板管理 | 统一的企业级文档模板，保证输出一致性 |

### 方案：新增文档输出Agent + 4个Skill

新增**文档输出Agent**，定位为团队最后一环，接收各Agent的Markdown产出物，按需输出专业格式文档。

**不将此能力分散到现有Agent的原因**：文档输出是跨领域关注点，涉及模板设计、排版规范、工具链使用，与业务逻辑无关，应由专职Agent统一处理。

### Agent定义

| 属性 | 内容 |
|------|------|
| 名称 | 文档输出Agent |
| 角色 | 将Markdown产出物转换为专业格式的Word/PDF/Excel/PPT文档 |
| 上游 | PM Agent（触发） |
| 下游 | 无 |

### 4个Skill定义

| Skill | 功能 | 实现方式 | 排版规范 |
|-------|------|----------|----------|
| word-export | 将需求/架构/技术设计等文档输出为Word | 使用Pandoc + 自定义Word参考模板（reference.docx） | 封面页、目录、标题层级、正文样式、页眉页脚、表格样式、代码块样式 |
| pdf-export | 将文档输出为PDF | 使用Pandoc + LaTeX模板 或 Pandoc + wkhtmltopdf | 与Word相同的排版规范，PDF固定版式，支持书签和超链接 |
| excel-export | 将表格类数据输出为Excel | 使用Python openpyxl库，读取Markdown表格转为Excel | 表头冻结、自动列宽、数据格式化、条件格式、Sheet分类、打印设置 |
| ppt-export | 将文档精简为演示文稿 | 使用Python python-pptx库，提取关键要点生成幻灯片 | 封面幻灯片、目录幻灯片、内容幻灯片（标题+要点列表）、总结幻灯片、统一配色和字体 |

```
├── skills/
│   └── doc-output/
│       ├── word-export/skill.md      ← 新增
│       ├── pdf-export/skill.md       ← 新增
│       ├── excel-export/skill.md     ← 新增
│       └── ppt-export/skill.md       ← 新增
├── templates/                        ← 新增：文档模板目录
│   ├── word/reference.docx           ← Word参考模板
│   ├── pdf/template.tex              ← LaTeX模板
│   ├── excel/style-config.json       ← Excel样式配置
│   └── ppt/template.pptx             ← PPT模板
```

## 执行步骤

| 序号 | 步骤 | 详细执行方式 |
|------|------|-------------|
| 1 | 创建文档输出Agent | 在`.ai-team/agents/doc-output/`目录下创建`agent.md`，定义角色、职责、输入输出、协作关系 |
| 2 | 创建word-export Skill | 在`.ai-team/skills/doc-output/word-export/`目录下创建`skill.md`，定义触发条件、执行步骤（读取Markdown→解析结构→选择模板→Pandoc转换→样式校验→输出到`output/`对应目录） |
| 3 | 创建pdf-export Skill | 在`.ai-team/skills/doc-output/pdf-export/`目录下创建`skill.md`，定义触发条件、执行步骤（读取Markdown→Pandoc+LaTeX转换→PDF生成→书签校验→输出） |
| 4 | 创建excel-export Skill | 在`.ai-team/skills/doc-output/excel-export/`目录下创建`skill.md`，定义触发条件、执行步骤（读取Markdown表格→openpyxl生成Excel→应用样式配置→自动列宽和冻结→输出） |
| 5 | 创建ppt-export Skill | 在`.ai-team/skills/doc-output/ppt-export/`目录下创建`skill.md`，定义触发条件、执行步骤（读取Markdown→提取标题和要点→python-pptx生成幻灯片→应用模板样式→输出） |
| 6 | 创建模板目录和模板说明 | 在`.ai-team/templates/`目录下创建4个模板说明文件，定义各模板的样式规范（字体、配色、布局、封面、页眉页脚等），后续由用户替换为企业实际模板 |
| 7 | 更新全局规则 | 在`.ai-team/rules/global-rules.md`中增加文档输出规则：各Agent完成产出后，PM Agent判断是否需要输出专业格式文档，如需则触发文档输出Agent |
| 8 | 更新.cursorrules | 增加文档输出Agent信息、4个Skill引用、templates目录说明 |
| 9 | 更新README.md | 更新目录结构和迁移说明 |
