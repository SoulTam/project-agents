## ③ 功能设计Agent产出 — 元数据规则完整行为定义

### 元数据格式
每篇文档的第1-2行（两行之间无空行）：
```
<!-- 创建时间: 2026-06-22 01:23 -->
<!-- 最后修改: 2026-06-22 01:23 -->
```

第3行为空行，第4行开始正文。

### 行为规则
| 场景 | 行为 |
|------|------|
| 创建新文档 | 自动写入 `创建时间` 和 `最后修改`（两者相同） |
| 更新已有文档 | 修改 `最后修改` 为当前时间，`创建时间` 保持不动 |
| 无文件变更（纯对话） | 不操作 |
| 排除源代码 | 仅对非代码文档执行，源代码不添加 |

## ④ 技术设计Agent产出 — 时间戳实现细节

### 时间格式
- 格式：`yyyy-MM-dd HH:mm`（24小时制）
- 获取命令：PowerShell `Get-Date -Format "yyyy-MM-dd HH:mm"`

### 创建文件时的流程
```
1. $now = Get-Date -Format "yyyy-MM-dd HH:mm"
2. 写入文件头：
   <!-- 创建时间: $now -->
   <!-- 最后修改: $now -->
   (空行)
   [文件正文]
```

### 更新文件时的流程
```
1. 读取文件 → 获取创建时间行（第1行）
2. $now = Get-Date -Format "yyyy-MM-dd HH:mm"
3. 替换第2行的最后修改时间
4. 保存文件
```

### 识别非代码文档的规则
```
排除的文件扩展名：.py .js .ts .java .css .scss .json .yaml .yml .toml .xml .sql .sh .bat .ps1
Doc后缀不包含源代码标识 → 纳入元数据
```
