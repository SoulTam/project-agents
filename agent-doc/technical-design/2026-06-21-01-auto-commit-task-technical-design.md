# 技术设计文档：修改任务完成后自动提交规则

## 实现路径
修改 AGENTS.md 中"Git 自动提交规则（所有阶段适用）"章节，新增一条规则定义。

## 新增规则内容

```
### 规则C：每次修改任务完成后自动提交

| 规则项 | 说明 |
|--------|------|
| 触发条件 | 任何修改任务（文件新增/修改、代码编写、文档更新）执行完毕后 |
| 执行操作 | `git add . && git commit -m "类型(范围): 描述"` |
| 提交信息格式 | 遵循 Conventional Commits：`类型(范围): 描述` |
| 冲突处理 | 与规则A/规则B同时触发时，只执行1次提交（通过 git status --porcelain 去重） |

> **例外**：无文件实际变更（git status --porcelain 无输出）时不触发。
```

## 去重策略
```
git status --porcelain → 无输出 → 跳过（无变更）
git log -1 --format=%s → 与本次信息相同 → 跳过（已提交）
```
